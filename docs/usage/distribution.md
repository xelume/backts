# 运行与分发

运行已构建的程序，准备静态资源并明确目标环境与进程重启要求。

先完成[构建与验证](testing.md)，准备应用二进制；静态文件应用还需阅读[静态资源](staticFiles.md)。

## 准备运行产物

构建机需要 Node、pnpm 和本机编译工具。应用产物是原生可执行文件；如果使用静态资源，还需带上资源目录。不能假定在 macOS 构建的文件可直接用于 Linux 或 Windows，应在目标环境验证工具链和运行行为。

## 启动程序

Todo 可直接按以下方式运行已构建产物：

```bash
cd examples/todo
./.scriptc/app 3000
```

在示例目录启动是因为它以 `./public` 注册静态资源。任意其他 cwd 可能导致目录找不到。应用也可以显式配置绝对资源路径，但框架目前没有统一配置加载器。

## 监听与部署环境

需要对外监听时，在应用启动参数中设置 host:true 或明确地址。当前 HTTP 服务没有内置 TLS、可信代理处理或生产认证组件；部署这些能力需要由应用和外部基础设施提供，并单独验证。

## 更新与重启

运行时无法自动重新加载源码；发布流程应替换构建产物并有序重启。进程内数据随退出丢失，需要持久化时使用应用自有存储实现。
